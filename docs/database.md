# Схема данных

Миграция `supabase/migrations/202607180001_initial_schema.sql` создаёт профили, роли, предпочтения, ответы анкеты, веса совместимости, объекты, изображения, избранное, группы, приглашения, заявки и события заявок, сообщения, уведомления, расходы, задачи, верификацию, AI-диалоги и аналитику.

Все доменные таблицы используют UUID и UTC timestamps. Внешние ключи удаляют дочерние сущности только там, где это безопасно (например, изображения объекта); профили собственников и авторы заявок защищены `on delete restrict`.

Для локального Supabase:

```bash
supabase db reset
npm run seed:users
supabase db seed
```

Seed ожидает минимум 20 подтверждённых Auth-пользователей. Скрипт пользователей требует только `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` и пароль из окружения.
