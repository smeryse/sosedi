# Demo-режим

Проект запускается без Supabase переменных. В этом режиме:

- `/app` и `/owner` используют реалистичные фикстуры из `data/demo.ts`;
- избранное, анкета, группа и заявки сохраняются в `localStorage` браузера;
- AI-помощник отвечает локальным mock-провайдером;
- карта показывает статический визуальный fallback.

Это режим для проверки UX и сценариев, а не замена RLS и Auth. Для production задайте `.env` и примените миграцию.
