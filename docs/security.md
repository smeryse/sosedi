# Безопасность

- Service role key не используется в клиентском коде и не добавляется в `.env.example` как public переменная.
- Включён RLS на всех таблицах приложения и на storage buckets. Публичны только опубликованные объекты, публичные профили без архива и подтверждённые статусы.
- Группы, заявки, сообщения, расходы и задачи читаются только участниками, авторами, собственниками соответствующего объекта или администраторами.
- Контакты не входят в публичный профиль. UI демонстрирует скрытие контактов до взаимного согласия; production endpoint должен придерживаться той же границы.
- AI получает только выбранный контекст профиля/группы. API-ключи и системные инструкции не передаются клиенту.
- Перед production нужно включить rate limiting для auth, сообщений и AI, антивирусную проверку вложений, email/phone verification и аудит admin-действий.
