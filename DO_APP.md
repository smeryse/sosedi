Ты работаешь внутри уже созданного репозитория веб-приложения «Соседи», основанного на Next.js Supabase App Template. Не создавай новый проект и не заменяй существующий репозиторий другим шаблоном. Сначала полностью изучи текущую структуру, package.json, App Router, конфигурацию TypeScript, Tailwind, Supabase-клиенты, middleware, существующую авторизацию, переменные окружения и компоненты. После аудита расширяй имеющийся проект аккуратно и последовательно.

Твоя задача — разработать полноценную промышленную коммерческую платформу совместной аренды жилья «Соседи». Это не учебный MVP, не статичный UI-концепт и не набор демонстрационных страниц. Все основные пользовательские сценарии должны быть связаны с Supabase, реальной моделью данных, серверной валидацией, Row Level Security, состояниями интерфейса, уведомлениями и тестами.

Продукт помогает людям находить совместимых соседей, формировать группы из 2–4 человек, подбирать квартиру под общий бюджет, общаться, отправлять групповую заявку собственнику и управлять совместной жизнью после заселения. Собственники размещают объекты, анализируют готовые группы, общаются с кандидатами и принимают решения по заявкам.

Не удаляй и не переписывай без необходимости рабочую инфраструктуру Next.js Supabase template. Используй уже созданные функции и клиенты Supabase, но приведи их к безопасной промышленной архитектуре. Не дублируй браузерный и серверный клиенты. Не создавай собственную систему авторизации. Не помещай service role key в клиентский код.

собственник управляет только своими объектами;
группа доступна её участникам;
заявка доступна участникам группы и собственнику объекта;
диалог доступен только его участникам;
сообщения доступны только участникам разговора;
закрытые данные профиля не выдаются публичному каталогу;
service role никогда не используется в браузере.

расходы;

разные результаты совместимости.

Имена, профили, объекты и истории должны быть вымышленными. Районы и улицы Краснодара могут быть реальными.

Создай безопасный серверный script для генерации тестовых Auth-пользователей.
